💡Relay & Traffic Light Hardware Status

Controls 4 lights across 2 gates using 2 Raspberry Pi GPIO pins. In normal/idle state, the relay is unenergized and current flows to the Red Lamp (Naturally Closed / NC). When access is granted, the relay energizes to switch to the Green Lamp (Normally Open / NO) for 5 seconds.

Entrance Gate (Entry) Hardware
Active Light: RED (STOP / IDLE)
Raspberry Pi Pin: GPIO 17 (Physical Pin 11)
Red: NC terminal · Green: NO terminal
Exit Gate (Departure) Hardware
Active Light: RED (STOP / IDLE)
Raspberry Pi Pin: GPIO 27 (Physical Pin 13)
Red: NC terminal · Green: NO terminal
Raspberry Pi 40-Pin Header Wiring Guide:
  • Entrance Relay IN1: Raspberry Pi GPIO 17 → Physical Pin 11
  • Exit Relay IN2: Raspberry Pi GPIO 27 → Physical Pin 13
  • Relay VCC: Raspberry Pi 5V Power → Physical Pin 2 or Pin 4
  • Relay GND: Raspberry Pi Ground → Physical Pin 6, Pin 9, or Pin 14
  • Light Common (COM): Power Source (+) connected to COM on both relay channels
  • Red Lights: Connected to NC (Normally Closed) → ON naturally at idle
  • Green Lights: Connected to NO (Normally Open) → ON when access granted
